DeepSeek Incognito — 隐私政策

最后更新：2026-10-09

1. 我们收集什么

本扩展仅在用户访问 chat.deepseek.com 时，读取浏览器发给 DeepSeek API 的 HTTP 请求头中的 Authorization 字段，用于在用户关闭标签页时调用 DeepSeek 的删除接口。该字段被临时缓存于浏览器本地（chrome.storage.session）。

本扩展不收集：浏览历史、其他网站数据、账号密码、聊天内容、个人信息。

2. 数据用途

临时缓存的 Authorization 令牌仅用于向 chat.deepseek.com 发起删除请求，删除用户在无痕模式下新建的对话。

3. 数据是否上传到第三方

否。所有数据仅保存在用户本机浏览器内，不经过任何第三方服务器，开发者本人也无法访问。

4. 数据保留策略

缓存的令牌保存在 chrome.storage.session 中，浏览器关闭后自动清除。无痕模式开关状态保存在标签页的 sessionStorage 中，标签页关闭后自动清除。

5. 用户控制

用户可随时在扩展界面中关闭无痕模式，或在浏览器扩展管理页面中卸载本扩展，所有本地数据将随之清除。

6. 权限说明

  • storage：保存无痕模式开关状态与待删除会话列表。
  • tabs：监听标签页关闭事件，触发删除操作。
  • webRequest：仅读取发往 chat.deepseek.com 的请求头中的 Authorization 字段。不读取、不修改、不阻断任何其他请求。
